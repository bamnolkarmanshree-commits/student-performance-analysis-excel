# Student Performance Analytics Dashboard | Microsoft Excel

## Project Overview
This project focuses on analyzing student performance using Microsoft Excel. The dashboard presents key metrics related to students' marks, attendance, assignment scores, and academic performance.

## Objectives
- Analyze student performance across different classes and subjects.
- Track average marks and attendance.
- Explore gender distribution.
- Identify the top-performing students.
- Understand monthly performance trends.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas and aggregations
- Slicers for interactive filtering
- Data visualization

## Key Performance Indicators (KPIs)
- Total Students
- Average Marks
- Average Attendance
- Highest Marks
- Total Assignment Score

## Dashboard Features
- Performance by Class
- Performance by Subject
- Monthly Performance Trend
- Gender Distribution
- Attendance Analysis
- Top 5 Students by Marks
- Interactive filters for Gender, Class, Subject, and Month
